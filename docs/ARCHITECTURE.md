# 架构设计

## L1 管理控制台

- 支持目标：C5
- 职责：按应用展示站点、版本、效果和活动，并发起联邦生成与版本下发。
- 边界：只调用管理 API，不读取数据库或工件正文。
- 依赖：L2

## L2 FedApp API 与确定性内核

- 支持目标：C1、C2、C4、C6
- 职责：协议校验、认证授权、幂等、应用隔离以及 Submission/Release/Delivery 状态机。
- 边界：不解释应用工件的业务语义，不决定站点是否采用版本。
- 依赖：L3、L5

## L3 应用联邦 Agent 与算法执行

- 支持目标：C3、C6
- 职责：每个应用域维护独立 Agent 配置和状态，调用绑定的版本化联邦算法。
- 边界：Agent 和算法不直连平台数据库或站点凭据；副作用由 L2 校验执行。
- 依赖：L2、L5

## L4 站点适配器

- 支持目标：C2、C4、C6
- 职责：在站点生成脱敏工件、主动上传、轮询命令、暂存候选版本并回报采用状态和评测。
- 边界：属于各应用实现；平台不进入站点私有网络，也不接收默认禁止的数据。
- 依赖：L2

## L5 持久化与部署

- 支持目标：C1、C2、C3、C4
- 职责：PostgreSQL 保存关系、状态、谱系和任务队列，S3-compatible 存储保存不可变工件内容。
- 边界：运行容器不保存持久业务数据。
- 依赖：无

## 已废弃架构项

无。
