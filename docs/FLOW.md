# 系统流程

## S1 应用注册

- 支持目标：C1、C6
- 输入：FedApp Manifest。
- 处理：校验协议和 schema，保存应用版本，自动创建唯一联邦域及 Agent，并绑定算法。
- 输出：可签发站点密钥的应用。
- 下一步：S2

## S2 站点上行

- 支持目标：C2
- 输入：应用密钥、应用版本、幂等键、Artifact Descriptor 和内容。
- 处理：认证、校验 digest/schema、保存工件和 Submission；首次成功上传自动形成 Membership。评测和贡献分别上传。
- 输出：可供查询或联邦选择的站点数据。
- 下一步：S3

## S3 联邦生成

- 支持目标：C3
- 输入：管理员选择的贡献 Submission。
- 处理：平台自动附带最新联邦版本，应用 Agent 调用本域算法；算法增量更新工件，平台保存输入、基础版本和输出谱系。
- 输出：新的不可变联邦版本。
- 下一步：S4

## S4 版本下发

- 支持目标：C4
- 输入：任一联邦版本及任意目标站点集合。
- 处理：平台创建 Delivery 和 stage 命令；站点轮询、下载、校验并回执。
- 输出：站点已暂存或拒绝的候选版本。
- 下一步：S5

## S5 站点采用与回传

- 支持目标：C4、C5
- 输入：站点本地测试结果和版本选择。
- 处理：站点自行采用、保留旧版或回退，并用独立 status/evaluation 请求回传实际版本和效果。
- 输出：可审计的站点版本状态与效果数据。
- 下一步：结束；新的贡献回到 S2。
